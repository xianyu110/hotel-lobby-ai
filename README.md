## 怎么用

1. 打开 [tryhotellobby.app](https://tryhotellobby.app)
2. 上传两张**不同人**的正脸照（左 / 右位）
3. 免费预览橙色棚构图 → 选画幅 → Create
4. Stripe：Single **$8.88** / 3-pack **$16.99** / 10-pack **$29.90**（约 **15 秒**）

---

## 产品要点

- 产品名 **LobbyDuo**：必须两张不同人的照片，对应棚内左/右
- 付费成片约 **15 秒**；可先免费预览构图再付款
- 原创 / AI 录音棚风格音轨，不含商业歌曲
- 独立工具，与原曲艺人及厂牌无关
